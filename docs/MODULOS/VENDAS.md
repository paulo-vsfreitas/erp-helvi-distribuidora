# Módulo Vendas

Fluxo principal:

```text
Venda
-> Cliente
-> Produtos
-> Pagamento
-> Finalização
-> Baixa de estoque
-> Conta a receber
-> Recebimento
-> Movimentação financeira
-> Histórico
```

Pendências:

- homologação integral;
- cancelamento com estorno;
- comparação de períodos;
- ranking de clientes;
- ranking de vendedores;
- exportações.
