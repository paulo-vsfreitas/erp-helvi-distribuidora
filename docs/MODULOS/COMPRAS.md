# Módulo Compras

Fluxo principal:

```text
Compra
-> Itens
-> Pagamentos
-> Recebimento
-> Entrada no estoque
-> Atualização do custo
-> Financeiro
-> Histórico
```

Pendências:

- cancelar compra recebida;
- editar itens;
- concluir histórico de entrada;
- revisar compra sem itens com pagamentos.
